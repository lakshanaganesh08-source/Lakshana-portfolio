# ProtoSem Asset Directory Structure

This directory holds the photography, diagrams, and prototype media for each week of the 20-week ProtoSem journey at Forge.

## Directory Structure:
- `assets/images/protosem/week-00/` (Week 00 - Completed)
- `assets/images/protosem/week-01/` (Week 01 - Completed)
- `assets/images/protosem/week-02/` (Week 02 - Completed)
- ...
- `assets/images/protosem/week-20/` (Week 20 - Final Prototype & Demo Day)

## Image Naming Convention:
Place photos inside the respective week folder using:
- `week-00-01.jpg`
- `week-00-02.jpg`
- `week-00-03.jpg`

Update `js/protosem-data.js` to reference the images when added.
