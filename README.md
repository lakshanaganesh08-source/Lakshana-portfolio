## 🌟 Overview

Personal portfolio website for **Lakshana G S**, showcasing projects, engineering experience, technical skills, certifications, and ProtoSem fellowship journey.

### ✨ Features
- **Modern Minimalist UI/UX**: Editorial typography, smooth micro-interactions, responsive design.
- **Project Showcase**: Highlights key projects such as *ConstructIQ*, *Smart Food Platform*, AI/ML systems, and Full Stack applications.
- **Experience & Education**: Timeline of professional background, roles, and academic achievements.
- **Certifications & Recognition**: Direct access to verified certificates and achievements.
- **ProtoSem Fellowship Journey**: Dedicated page documenting week-by-week learnings and prototype milestones.
- **Interactive Contact**: Social channels, resume download, and direct communication channels.

## 🚀 Getting Started

### Quick Start (Recommended)
```bash
# Start the local server
npm start
```
Then open [http://localhost:8080](http://localhost:8080) in your browser.

### Alternative Options
- **Direct Node execution:**
  ```bash
  node server.js
  ```
- **Using Python:**
  ```bash
  python -m http.server 8080
  ```
- **Direct browser opening:**
  Double-click `index.html` or right-click -> Open with Chrome / Edge / Firefox.
- **VS Code Live Server:**
  Right-click `index.html` -> *Open with Live Server*.
